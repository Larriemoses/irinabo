# AI-assisted decisions

## Self-contained judge mode

The specification requires an honest fallback when a judge cannot join the WhatsApp Sandbox. Judge Mode and the browser demonstration remain available without external credentials. The browser report experience is therefore treated as a **simulated presentation flow**, not as evidence that a WhatsApp message was delivered.

The repository also contains a signed Twilio webhook and live-capable WhatsApp adapter. Deployment status must be labelled from actual end-to-end evidence rather than from code presence alone.

## Deterministic security boundary

Fixed functions select access, routing and incident state transitions. AI is limited to source-linked suggestions and a deterministic fallback. AI cannot choose recipients, grant access, decide truth or mark an incident resolved.

## Protected-by-default safety principle

A report that may involve transport staff must not be exposed to ordinary garage roles while the protection decision is unresolved. The routing helpers and role checks encode this boundary.

## Evidence over aspiration

The submission distinguishes implemented code from demonstrated integrations. Voice-note transcription, WhatsApp current-location ingestion, external telephone escalation and automatic public-agency dispatch are not presented as live unless separately implemented and tested.
