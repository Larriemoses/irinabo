# AI-assisted decisions

## Self-contained judge mode before external credentials

The specification requires an honest fallback when a judge cannot join the WhatsApp Sandbox. The browser flow, role rules and receipts therefore run locally, while WhatsApp and voice remain `SIMULATED` until configured.

## Deterministic security boundary

Fixed functions select and lock routing. AI is limited to source-linked suggestions and a deterministic fallback. This follows Sections 8, 11, and 13 of the specification.
