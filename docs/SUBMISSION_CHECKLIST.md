# IrinAbo submission checklist

## Repository

- [ ] Merge the submission-readiness pull request.
- [ ] Confirm the latest Vercel deployment is green.
- [ ] Open every public demo link in a private browser window.
- [ ] Confirm `pnpm test`, `pnpm lint` and `pnpm build` pass.
- [ ] Confirm the README matches the deployed behaviour.

## Demo video

- [ ] Follow `docs/DEMO_SCRIPT.md`.
- [ ] Keep the recording close to two minutes.
- [ ] Show the public report, read-only case, journey page, receipt and Judge Mode.
- [ ] Say that all people and incidents are fictional.
- [ ] Never claim that a real WhatsApp message, call or agency dispatch occurred.
- [ ] Export an accepted format below 250 MB.

## Pitch deck

- [ ] Export the final deck as PDF below 100 MB.
- [ ] Verify every slide at full-screen size.
- [ ] Keep live, simulated and deferred claims consistent with Judge Mode.

## Written summary

- [ ] Paste the final text from `docs/SUBMISSION_SUMMARY.md`.
- [ ] Preserve the track, source, trust and AI-tool sections.
- [ ] Check the portal character limit before pasting.

## Portal

- [ ] Repository URL is public.
- [ ] Live prototype URL opens without authentication.
- [ ] Video plays after upload.
- [ ] Pitch deck PDF opens after upload.
- [ ] Written summary has no truncated paragraphs.
- [ ] Save once, reopen the submission and check all four items.
